# Nexova

**Think. Build. Repeat.**

A bold product landing page with a ping-pong looping video backdrop, masked word-reveal typography, an oversized kinetic wordmark, and a custom glass cursor that follows the pointer with spring physics.

## Tech Stack

- Next.js
- TypeScript
- Framer Motion
- Lenis
- CSS Masking

## Features

- Ping-pong looping video backdrop
- Masked word-reveal typography
- Oversized kinetic wordmark
- Custom glass cursor with spring physics
- Smooth scroll with Lenis
